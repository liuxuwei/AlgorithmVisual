# Spec Delta

## Purpose

定义应用如何从网络获取 LeetCode 热题 100 题库内容，并在网络不可用或 Web 端受限时通过本地缓存与内置快照保持题库可用，同时以稳定标识支撑题目到可视化的映射。

## ADDED Requirements

### Requirement: 网络获取热题 100 题库列表

系统 SHALL 通过 LeetCode 网页端 GraphQL 接口获取官方「热题 100」题库列表，一次请求返回 100 道题及其 17 个专题分组。每道题 MUST 包含稳定标识 titleSlug、题号、中文标题、难度和所属专题分组。

#### Scenario: 成功拉取完整题库列表

- **WHEN** 应用启动且网络可用
- **THEN** 系统获取到 100 道题，按 17 个专题分组组织，每题带 titleSlug、题号、中文标题、难度

#### Scenario: 接口返回题目数量异常

- **WHEN** 网络接口返回的题目数量不等于 100 或结构不符合预期
- **THEN** 系统判定该次拉取失败并改用内置兜底快照，不展示残缺列表

### Requirement: 单题题面按需获取

系统 SHALL 在用户打开某道题时按需获取该题的中文题面内容，MUST NOT 在启动阶段一次性请求全部 100 道题的题面。题面获取成功后 MUST 与该题 titleSlug 关联缓存。

#### Scenario: 首次打开题目拉取题面

- **GIVEN** 题库列表已加载但该题题面尚未缓存
- **WHEN** 用户打开该题详情
- **THEN** 系统按 titleSlug 请求题面并展示，同时写入缓存

#### Scenario: 再次打开题目直接使用缓存

- **GIVEN** 该题题面已缓存
- **WHEN** 用户再次打开该题详情
- **THEN** 系统直接展示缓存题面，不重复发起网络请求

### Requirement: 内置兜底快照

应用包 SHALL 内置一份与网络结构一致的题库快照，包含 100 道题的元数据、专题分组与题面。当网络获取失败、超时或被浏览器 CORS 拦截时，系统 MUST 使用快照提供完整题库浏览与可视化，MUST NOT 出现空白页或阻塞式错误。

#### Scenario: 断网时使用快照

- **GIVEN** 设备无网络连接
- **WHEN** 应用启动
- **THEN** 系统从内置快照加载 100 道题，列表、题面与可视化均可正常使用

#### Scenario: Web 端被 CORS 拦截时使用快照

- **GIVEN** 应用运行在浏览器中且网络请求被跨域策略拦截
- **WHEN** 应用启动
- **THEN** 系统自动降级到内置快照，题库功能保持完整

### Requirement: 本地缓存与刷新

系统 SHALL 在网络获取成功后缓存题库列表与题面，缓存 MUST 以 titleSlug 作为题目的关联键。后续启动 MUST 优先展示缓存内容，并在后台尝试刷新；刷新失败 MUST 保留已有缓存，不得清空。

#### Scenario: 二次启动使用缓存

- **GIVEN** 上一次运行已成功缓存题库
- **WHEN** 应用再次启动
- **THEN** 系统立即展示缓存内容，不等待网络请求完成

#### Scenario: 缓存损坏回退快照

- **WHEN** 缓存的题库数据无法解析
- **THEN** 系统丢弃该缓存并使用内置快照，题库仍可正常浏览

### Requirement: 稳定题目标识

系统 SHALL 以 titleSlug 作为题目的唯一稳定标识，用于缓存、题面请求、可视化脚本映射与页面跳转。中文标题或题号变化 MUST NOT 影响题目定位。

#### Scenario: 标题变化不影响定位

- **GIVEN** 某题的网络中文标题发生变化
- **WHEN** 系统按 titleSlug 查找该题
- **THEN** 仍能定位到同一道题及其对应的可视化

### Requirement: 题库加载状态与重试

系统 SHALL 向用户展示题库加载状态。网络请求失败但快照可用时 MUST 以非阻塞方式提示当前为离线数据，并提供手动重试入口。

#### Scenario: 离线数据提示

- **WHEN** 系统降级到内置快照
- **THEN** 界面提示当前展示的是离线题库，并显示重试按钮

#### Scenario: 重试成功后切换在线数据

- **GIVEN** 当前处于离线快照状态
- **WHEN** 用户点击重试且网络恢复可用
- **THEN** 系统切换为在线题库数据并移除离线提示

### Requirement: 题面可读展示

系统 SHALL 将题面以可读形式展示，保留段落、代码块、列表等基本排版。题面中的 HTML 标记 MUST NOT 以原始标签文本直接呈现给用户。

#### Scenario: 展示带代码块的题面

- **WHEN** 用户打开题面包含代码块和列表的题目
- **THEN** 界面按段落与代码块排版展示，不出现未解析的 HTML 标签
